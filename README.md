# Google-HomePage


A detailed recreation of the classic Google homepage built using pure HTML and CSS.
This project focuses on recreating the visual appearance and basic interaction of Google's landing page while practicing frontend fundamentals.

---

# Project Overview

This project is a frontend clone of the Google homepage that includes:

* A custom address/search bar
* Styled search input field
* Hover and focus effects
* Google logo recreation
* Interactive buttons
* Working external links
* Embedded icons/images using Base64
* Clean page structure using HTML and CSS only

The goal of this project was to improve frontend development skills and gain hands-on experience with webpage layout, styling, positioning, and UI recreation.

---

# Features

## Google Style Homepage

The webpage visually recreates the classic Google homepage interface with centered content and clean spacing.

## Search Bar UI

Includes a large styled search bar with:

* Rounded corners
* Focus border effects
* Embedded search icon
* Google-like layout styling

## Address Bar Simulation

A browser-style address/search bar is added at the top for extra realism.

## Interactive Buttons

The page includes:

* **Google Search** button
* **I'm Feeling Lucky** button

Both buttons are fully clickable and redirect users to real Google-related pages.

### Button Functionality

| Button            | Action                        |
| ----------------- | ----------------------------- |
| Google Search     | Opens real Google search page |
| I'm Feeling Lucky | Opens Google Doodles page     |

### Arts & Technology Link
